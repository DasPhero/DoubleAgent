# DoubleAgent — User Handbook

Welcome to the DoubleAgent user handbook.

## Overview

DoubleAgent is a cross-platform (Windows and Linux) native SSH client featuring an encrypted local vault, tabbed and split-pane terminals, SFTP file transfers, port forwarding, TOTP generation, and per-host notes.

## Current Capabilities (`M0`, `M1-1`, `M1-2`, `M1-3`, `F-08`, `F-10`, `F-12`, `F-13`, `F-14`, `F-15`, & `F-23`)

- **Standalone Native App (`M0-0`)**: Launches directly as a single executable on Windows (`DoubleAgent.exe`) and Linux without external runtime dependencies.
- **Command Snippets with Dynamic Variables (`F-15`)**:
  - **Encrypted Vault Storage**:
    - Store frequently used commands, scripts, diagnostics, and deployment snippets inside your encrypted vault.
    - Categorize snippets with searchable tags (e.g. `docker`, `k8s`, `logs`, `network`, `db`).
    - Dedicated management modal accessible via **Tools ▾ -> Automation & Snippets (F-15)** or the `⚡ Snippets` button in any terminal header.
  - **Auto-Injected Context Variables**:
    - Automatic variable substitution based on the active target session:
      - `{{HOST}}`, `{{IP}}`, `{{HOSTNAME}}`: Target host address or resolved IP.
      - `{{USER}}`: Resolved effective username of the target session.
      - `{{PORT}}`: Target SSH or service port.
      - `{{CWD}}`: Current working directory of the active session (detected via OSC 7 escape sequence or default host directory).
      - `{{TIMESTAMP}}`, `{{DATE}}`, `{{TIME}}`: Local timestamps formatted for logs and backups.
      - `{{LOCAL_IP}}`: Local non-loopback network interface address.
      - `{{PASSWORD}}`: Host authentication password securely resolved directly within the backend Go process (never exposed in cleartext to the frontend).
  - **Custom User Parameters & Syntax**:
    - Define interactive variables with optional defaults and descriptions:
      - `{{INTERFACE=eth0}}`
      - `{{COUNT=4:Number of pings}}` or `{{COUNT=4 | Number of pings}}`
      - `{{IMAGE=nginx:alpine}}` (preserves colons within default values)
  - **Interactive Parameter Query Modal (`SnippetRunModal`)**:
    - Before execution, DoubleAgent automatically inspects the command template. If custom parameters exist or if **Always prompt before running** is enabled, an interactive modal pops up.
    - Auto-populates detected built-in context parameters with live session details.
    - Real-time command preview dynamically updates syntax substitutions as you type.
    - Options to **Copy to Clipboard** or **⚡ Run in Terminal** directly piping to SSH, local PTYs, or serial consoles.
  - **Command Palette & Search Integration**:
    - Search and run snippets directly from `Ctrl+K` Command Palette.
- **Proxy Profiles: ProxyJump, ProxyCommand, & proxychains Export (`F-14`)**:
  - **Proxy Profiles in Encrypted Vault**:
    - Configure reusable proxy profiles under **Tools ▾ -> Proxy Profiles (F-14)**:
      - **ProxyJump Chains**: Define intermediate bastion/jump hosts (`[user@]host[:port]` or select from existing saved hosts). Chain through multiple hops sequentially (e.g. `bastion-dmz ➔ internal-jump ➔ target-server`).
      - **ProxyCommand**: Execute custom proxy helper commands locally (e.g. `connect-proxy -S proxy:1080 %h %p`, `nc -X 5 -x 127.0.0.1:1080 %h %p`, `ncat --proxy-type socks5 %h %p`). Macro expansion dynamically substitutes `%h` with the target host and `%p` with the target port. Windows commands run headlessly with `CREATE_NO_WINDOW`.
      - **SOCKS5 Proxies**: Tunnel SSH connections directly through corporate or dynamic SOCKS5 proxies (`host:port`) with optional username and password authentication.
    - Passwords for authenticated proxies are stored in the encrypted vault and never exposed in cleartext to the frontend.
  - **Host & Group Proxy Assignment & Inheritance**:
    - Assign a Proxy Profile to any SSH Host or set a default Proxy Profile on a Host Group to have all member hosts inherit the proxy settings automatically.
    - Override jump chains or proxy commands on individual hosts when needed.
  - **Export `proxychains.conf`**:
    - Open **Tools ▾ -> Export proxychains.conf** or click **Export proxychains.conf** in the Port Forwarding view.
    - Automatically collects all active and saved dynamic SOCKS5 forward rules (`-D`) and SOCKS5 proxy profiles.
    - **Configurable Options**:
      - Chain Modes: `strict_chain` (traverse all proxies in order), `dynamic_chain` (skip offline proxies), `random_chain`, `round_robin_chain`.
      - DNS Leak Prevention: Toggle `proxy_dns` to route all DNS queries through the proxy chain.
      - Quiet Mode: Suppress proxychains banner output.
      - Timeouts: Configure connect timeout (ms) and data read timeout (ms).
      - Proxy List Editor: Reorder hops, toggle individual proxies on/off, edit type (`socks5`, `socks4`, `http`), host, port, user, and password.
    - **Export Options**: Real-time configuration preview, **Copy to Clipboard**, **Download .conf**, and **Save to Disk** (`proxychains.conf` or `proxychains4.conf`).
- **Port Forwarding: Local `-L`, Remote `-R`, & Dynamic SOCKS5 `-D` (`F-13`)**:
  - **Rule Storage & Management in Encrypted Vault**:
    - Configure persistent port forwarding rules stored securely in the encrypted vault (`ForwardRules`).
    - Color-coded badges for quick identification:
      - **Local Forwarding (`-L`)** (Green): Listen on a local port and tunnel connections to a remote target through SSH.
      - **Remote Reverse Forwarding (`-R`)** (Purple): Listen on a remote server port and tunnel connections back to a local machine port.
      - **Dynamic SOCKS5 Proxy (`-D`)** (Amber): Turn any SSH connection into an RFC 1928 compliant SOCKS5 proxy on a local port to route arbitrary application traffic (browsers, curl, tools).
    - Configurable rule parameters: Label/Description, Associated Host, Auto-Start toggle, Bind Address, Bind Port, Target Host, and Target Port.
  - **Status Indicators & Live Traffic Metrics**:
    - Real-time status badge (`ACTIVE` with green glow / `INACTIVE`).
    - Bidirectional live traffic counters: `In: <bytes>` and `Out: <bytes>`.
    - Active concurrent connection counter: `<count> active connection(s)`.
    - Mapping diagram preview: `<bindAddress>:<bindPort> ➔ <targetHost>:<targetPort>`.
  - **Auto-Start with Host**:
    - Rules flagged with **Auto-start** automatically spin up their background tunnels as soon as you connect to their associated host (`ConnectSavedHost`).
  - **Multi-Tunnel Control**:
    - Start and stop individual tunnels on demand.
    - Top navigation bar displays a live indicator pill (`⚡ N Tunnels` / `Tunnels ⇄`) showing the number of active tunnels at a glance.
    - Dedicated management modal accessible via the top bar button or **Tools ▾ -> Port Forwarding (-L, -R, -D)**.
- **Two-Column SFTP File Browser & Transfer Queue (`F-12`)**:
  - **Two-Column Layout (Local ↔ Remote)**:
    - Side-by-side view with your local filesystem on the left and the remote host's filesystem on the right.
    - Responsive table showing entry name, formatted size, last modified timestamp, and UNIX file permissions.
    - Folders clearly distinguished by folder icons (📁) and sorted to the top; double-click any directory to enter.
  - **HTML5 Drag-and-Drop File Transfers**:
    - Drag files from the Local panel and drop them directly onto the Remote panel to trigger an immediate background upload.
    - Drag files from the Remote panel and drop them onto the Local panel to trigger an immediate background download.
    - Visual blue drop target highlights when dragging over target panes.
  - **Transfer Queue with Live Progress & Cancellation**:
    - Collapsible bottom drawer displaying all active, queued, completed, failed, and cancelled transfers.
    - Real-time progress bar (0–100%), transferred bytes vs. total size, and dynamic transfer speed (e.g. `1.2 MB/s`).
    - **One-Click Cancellation**: Click the **`✕`** button on any running transfer to abort it immediately.
    - **Clear Finished**: One-click cleanup button to clear completed or failed items from the queue.
  - **Remote File & Folder Management**:
    - **New Remote Folder (`📁+`)**: Create new remote directories directly from the toolbar dialog.
    - **Delete Remote Item (`🗑`)**: Remove remote files or directories with a safety confirmation prompt.
    - **Upload (`Upload ➔`) & Download (`⬅ Download`)**: Dedicated action buttons for quick one-click transfers.
    - **Directory Navigation**: Breadcrumb path input bar, Go Up (`⬆ Up`) to parent directory, and Refresh (`↻`).
  - **Seamless Launching**:
    - Click **`SFTP`** on any saved host in the sidebar to connect and open its file browser.
    - Click **`📁 SFTP`** in the header of any active SSH terminal pane.
    - Select **SFTP File Browser (F-12)** from the top **Tools ▾** menu.
- **New Terminal by Working Directory & Elevated Root Shell (`F-10`)**:
  - Open new tabs or split panes directly positioned in specific directories without having to manually `cd`:
    - **Default Directory (`🏠 Default Dir`)**:
      - Configurable per-host and inherited from group defaults (`InitialDir`) directly in the Add/Edit Host and Group dialogs.
      - When configured, connecting to a saved host automatically starts in its specified directory.
      - Spawns a new tab/pane positioned in the host's configured default directory or user home.
    - **Current Directory (`📂 Current Dir`)**:
      - Automatic real-time working directory detection via **OSC 7** shell escape sequences (`file://hostname/path`).
      - Displays the live working directory pill (`📂 /path/to/cwd`) in the pane header and sidebar host badges.
      - Spawns a duplicate tab or split pane positioned in the exact CWD of the active session. If no session is active, prompts for a target directory.
    - **Elevated Root Shell (`⚡ Root in Dir`)**:
      - Spawns an elevated/root terminal session (`sudo -s` or WSL/ConPTY root) positioned in the active terminal's CWD.
      - Visual red indicator badge (`Root`) in the tab title and accent color.
    - Accessible via toolbar action buttons on active sessions, the **Empty State Quick-Start Grid**, and through the **Tools ▾** menu at all times.
- **Local Terminals & Native Windows ConPTY (`F-23`)**:
  - **Native Headless ConPTY Engine**:
    - Windows local shells (PowerShell, Command Prompt, WSL) run entirely headlessly inside xterm.js via Windows Pseudo Console (`CreatePseudoConsole`), with zero external console popups.
    - Full interactive VT command streaming, prompt rendering, line editing, and resize support.
  - **Local PTY Terminals (PowerShell, Command Prompt, WSL)**:
    - Open local terminals directly inside DoubleAgent tabs from **Tools ▾** or the **Empty State Quick-Start**:
      - **Local Shell (PowerShell)**: Launches `powershell.exe` with interactive streaming.
      - **Local Shell (Command Prompt)**: Launches `cmd.exe`.
      - **Local Shell (WSL Linux)**: Launches `wsl.exe` for your default Linux distribution.
    - Local sessions integrate seamlessly with the Tab manager, Split Panes, per-pane font zoom, and in-terminal search (`Ctrl+F`).
  - **Hardware Serial / UART / RS-232 / USB Console (`F-23`)**:
    - Connect to microcontrollers, embedded boards, network switches, routers, and serial devices via COM ports on Windows (`COM1`–`COM256`) and `/dev/ttyUSB*` / `/dev/ttyS*` on Linux.
    - **One-Click Auto-Detect (`⚡ Auto Detect Port & Baud`)**:
      - Click **`⚡ Auto Detect Port & Baud`** in the connection dialog to probe active hardware ports, identify the target device, and auto-configure optimal baud rates (e.g. 115200, 9600, etc.) with real-time confidence feedback.
    - **Port Detection**: Automatic hardware port enumeration with a one-click **`🔄 Refresh`** button.
    - **Baud Rates**: Select standard rates (`9600`, `19200`, `38400`, `57600`, `115200`, `230400`, `460800`, `921600`, up to `2000000` baud).
    - **Configurable Parameters**: Data Bits (5-8), Parity (None/Odd/Even/Mark/Space), Stop Bits (1/1.5/2), Flow Control (None/Hardware/Software), Line Endings (CRLF/LF/CR), and Local Echo.
    - **Hardware Pin Controls & Break Signal**:
      - Toggle **DTR** and **RTS** pin states directly from the pane header in real-time.
      - Send a hardware **`⚡ Break`** condition signal for microcontroller reset or ROM monitor entry.
  - **Saleae-style Digital Signal & Logic Analyzer**:
    - Click **`📈 Logic Analyzer`** in any serial pane header to open an interactive digital oscilloscope & logic analyzer view.
    - **Multi-channel Digital Waveforms**: Live digital square waves for **RX (CH 0)**, **TX (CH 1)**, **DTR (CH 2)**, and **RTS (CH 3)**.
    - **UART 8N1 Protocol Decoder**: Synthesizes and plots Idle HIGH, Start bit LOW, 8 Data bits (LSB-first), and Stop bit HIGH.
    - **Saleae-Style Decoded Packet Bubbles**: Displays decoded ASCII characters and hex bytes (e.g. `'A' 0x41`, `'\n' 0x0A`) positioned directly above the waveform pulses.
    - **Interactive Controls**: Play/Pause live capture, horizontal drag-and-scrub pan, Zoom In (`+`), Zoom Out (`-`), Reset Zoom, Clear buffer, and channel toggles.
- **Top Bar Menu Navigation & Workspace Organization**:
  - The top bar is organized into a clean application menu bar rendered in front of all panels:
    - **Hoverable Menus**: Dropdowns open smoothly on mouse hover and allow seamless mouse movement across menus.
    - **Vault ▾**: Quick access to lock/unlock, Vault Security & Windows Hello (`F-03`), and emergency Vault Reset.
    - **Tools ▾**: Direct triggers for Command Palette (`Ctrl+K`), Keychain (`F-04`), Import `ssh_config` (`F-22`), Local Shells, Serial Console, and one-click session password injection.
    - **View ▾**: Toggle sidebar, split pane horizontal/vertical triggers, toggle host-grouped tabs (`F-09`), toggle signal analyzer, and pane font zooming (`Ctrl +` / `Ctrl -` / `Ctrl 0`).
    - **Settings ⚙**: Instant access to Global Settings (`Ctrl+,`).
- **Collapsible Sidebar (`Ctrl+B`)**:
  - Click **`◀`** in the sidebar header (or select **Toggle Sidebar** in the View menu / press **`Ctrl+B`**) to collapse the Hosts & Groups sidebar into a slim 40px vertical strip, giving 100% of the display width to your active terminal panes.
  - Click **`▶`** or press **`Ctrl+B`** to expand it back instantly.
- **Immediate Startup Unlocked State**:
  - DoubleAgent starts directly in the unlocked state with the active color theme (Teal default), allowing immediate connection and terminal usage without requiring setup hurdles. Vault password security can still be configured at any time via Vault Security.
- **Host Color Coding & Tab Groups (`F-09`)**:
  - **Host Color Tags**: Pick from 9 curated palette colors (Emerald, Sky, Amber, Rose, Violet, Cyan, Indigo, Pink, Slate) or use automatic deterministic colors in the Add Host dialog.
  - Colors are clearly displayed as color indicator dots in the sidebar host list and as accent top-borders on open tabs.
  - **Expandable / Collapsible Tab Groups**:
    - Click **`⊞ Group by Host`** in the tab bar (or View menu) to cluster all sessions connected to the same host under a color-coded host header pill.
    - Shows host session count badge (e.g. `2`).
    - Click the group header chevron (`▾`/`▸`) to collapse all sessions of that host to save space, or expand to display all tabs side-by-side.
    - Click **`⊟ Ungroup`** at any time to return to the standard flat tab view with drag-and-drop ordering.
- **In-Terminal Search & Match Highlighting (`F-11`)**:
  - Press **`Ctrl + F`**, click **`🔍 Find`** in any pane header, or select **Find in Terminal** in the View menu.
  - Floating search widget overlays in the top right of the terminal without obscuring your prompt.
  - **Live Incremental Search**: Highlights all matching occurrences across the buffer (up to 1,000 matches) with distinctive active/passive match colors.
  - **Search Controls**:
    - **Previous / Next Match**: Press `Enter` or click `▼` for next match; press `Shift + Enter` or click `▲` for previous match.
    - **Match Case (`Aa`)**: Toggle case-sensitive matching.
    - **Whole Word (`\b`)**: Match whole words surrounded by non-word boundaries.
    - **Regular Expression (`.*`)**: Full regex matching across the terminal scrollback buffer.
  - **Clean Dismissal**: Press `Escape` or click `×` to close the search widget, clear highlights, and immediately return keyboard focus to the remote shell.
- **Global Settings & Theme Customization (`F-08`)**:
  - Open the **Global Settings** modal anytime by pressing **`Ctrl+,`** or clicking **Settings ⚙** in the top navigation bar or sidebar.
  - **Color Themes**: Choose between **Teal (Cyber Teal Default)**, **Dracula**, **One Dark**, **Nord**, **Monokai Pro**, and **Crimson**. The entire app window, borders, active focus indicators, and terminal color palette instantly switch in real-time.
  - **Terminal Font & Cursor Configuration**: Configure default font family (Cascadia Code, JetBrains Mono, Fira Code, Consolas, Source Code Pro), default font size (9–32px), line height (1.0–1.4), cursor style (Block, Underline, Bar), cursor blinking, and scrollback depth (up to 50,000 lines). All settings persist across sessions in local storage.
  - **Keyboard Shortcuts Reference**: View all active workspace shortcuts in one clear table.
- **Visual Security State (Dark Crimson Locked ↔ Theme Unlocked)**:
  - When the **Vault is Locked**, the entire application displays a **Dark Crimson / Red** theme so you can see at a glance that secrets are locked.
  - As soon as you unlock the Vault, the UI transitions to your selected theme (Teal by default).
- **Multi-Session Tabs & Arbitrary Mixed Split Panes (`F-08`)**:
  - Connecting to multiple hosts (or multiple times to the same host) opens each session in its own **Tab** in the top tab bar.
  - **Preserved Terminal Logs Across Splits & Tab Switches**: Utilizing a persistent `TerminalPool`, all running session logs, command outputs, active screen buffers, and scrollback are 100% preserved when splitting panes horizontally/vertically or switching tabs.
  - **Isolated Terminal Scrolling**: Scrolling inside a terminal pane never bubbles up or causes the DoubleAgent window/workspace to scroll (`overscroll-behavior: contain` + overflow locking).
  - **Per-Pane Font Zoom Controls**:
    - Zoom terminal text in any pane via the **`+`** and **`-`** buttons in the pane header, or press **`Ctrl +`** / **`Ctrl -`** (or **`Ctrl + MouseWheel`**).
    - Press **`Ctrl + 0`** to quickly reset the pane's font size to the global default. Current font size is displayed dynamically in each pane header (e.g. `14px`).
  - **Drag-and-Drop Reordering**: Drag any tab pill left or right to reorder your open sessions.
  - **Mixed Nested Splitting**:
    - Click **Split ⬌** (`Split Horizontal`) or **Split ⬍** (`Split Vertical`) to divide any active pane.
    - Supports arbitrary nested combinations (e.g. splitting horizontally and then splitting the left pane vertically creates two stacked panes on the left alongside a full-height pane on the right).
  - **Close Individual Panes**: Every pane in a split grid has its own **`×`** close button in its header, allowing individual panes to be closed independently. When all panes in a tab are closed, the tab automatically closes.
  - **Keyboard Focus Navigation**:
    - Press **`Alt+ArrowLeft`** / **`Alt+ArrowRight`** to navigate between open **Tabs**.
    - Press **`Alt+ArrowUp`** / **`Alt+ArrowDown`** (or click **Next Pane ⇥**) to cycle keyboard focus between **Split Panes** without sending raw terminal escape characters (`A`, `B`, `C`, `D`).
- **Local Terminals & Hardware Serial / UART Console with Auto-Detect & Logic Analyzer (`F-23`)**:
  - **Local PTY Terminals**: Launch native PowerShell (`powershell.exe`), Command Prompt (`cmd.exe`), or WSL (`wsl.exe`) local shells from the **Tools ▾** menu.
  - **Hardware Serial / UART Console**:
    - Select detected COM ports with intelligent hardware identification (FTDI, CP210x, CH340/CH341/CH343/CH347, ESP32, Arduino, Raspberry Pi Pico, STM32 VCP).
    - Port dropdown categorizes active connected devices (`🟢 Connected & Active Hardware`) vs offline/dormant ports, displaying full Vendor, Hardware ID (VID/PID), and connection status.
    - Click **⚡ Auto Detect Port & Baud** to automatically test COM ports and probe candidate baud rates (from 9,600 to 2,000,000 baud) for valid character framing.
    - Real-time line controls for DTR, RTS, and manual Break signals (`SetCommBreak`).
  - **Saleae-style Signal & Logic Analyzer**:
    - Click **📊 Signal Analyzer** on any active serial tab to open an embedded digital logic analyzer canvas.
    - Synthesizes and captures digital bit waveforms for RX, TX, DTR, and RTS signals with timing grids, zoom/pan navigation, and decoded protocol bubble overlays (e.g. `'A' 0x41`).
- **Collapsible Sidebar & Hover Navigation**:
  - Collapse the left Hosts & Groups sidebar with **`Ctrl+B`** or the header toggle button (`◀`/`▶`) for maximum terminal workspace.
  - Hover over header menus (**Vault ▾**, **Tools ▾**, **View ▾**) with seamless hit-testing bridges and stable debounced navigation.
- **SSH Keychain (`M1-3` — `F-04`)**:
  - Click **Keychain (`F-04`)** in the top bar when the Vault is unlocked:
    - Generate new **Ed25519** or **RSA-3072** SSH keypairs directly inside the encrypted Vault (with an optional passphrase).
    - Import existing **OpenSSH PEM** or **PuTTY `.ppk`** (`v2` and `v3`) private keys.
    - Click **Copy Public Key** on any saved key to copy its `authorized_keys` line to the clipboard.
- **SSH Agent & Pageant Integration (`M1-3` — `F-05`)**:
  - When adding a Host, choose **Windows OpenSSH Agent / Pageant (`F-05`)** as the authentication method to authenticate via your OS SSH agent (`\\.\pipe\openssh-ssh-agent`, Pageant shared memory, or Unix `SSH_AUTH_SOCK`) without storing the private key inside the Vault.
- **OpenSSH `ssh_config` Import (`M1-3` — `F-22`)**:
  - Click **Import `ssh_config`** in the top bar and paste your `~/.ssh/config`.
  - Automatically imports `Host`, `HostName`, `User`, `Port`, `IdentityFile`, and `ProxyJump`, and displays clear warnings for any unsupported directives.
- **One-Click Password Injection into Active Terminal Sessions**:
  - While connected to an SSH terminal session, click **Inject Password** in the terminal toolbar to have the Go backend write the stored password directly into the remote PTY (`stdin`) for `sudo` / `su` prompts without ever exposing the password to the frontend.
- **Command Palette & Quick Connect (`M1-2` — `F-02`)**:
  - Press **`Ctrl+K`** (or click **Command Palette (`Ctrl+K`)** in the top bar) from anywhere in the workspace.
  - **Fuzzy Search**: Type fragments or subsequences of a host's **Name** (e.g. `pw01` for `prod-web-01`), **IP/Hostname**, or **Tags** (e.g. `nginx`) and press `Enter` (or click the result) to connect immediately.
  - **Direct `user@host:port` Quick Connect**: Type `user@host:port`, `user@host`, `host:port`, or `ssh -p 2222 user@host` into the Command Palette to connect to an ad-hoc SSH target directly.
- **Hosts & Groups Management with Inheritance (`M1-1` — `F-01`)**:
  - Once unlocked, use the left **Hosts & Groups** sidebar:
    - Click **+ Group** to create hierarchical folders with default **Port**, **Username**, and **Keepalive** settings.
    - Click **+ Host** to save an SSH host inside the encrypted Vault. Leave Port (`0`) or Username empty to inherit them automatically from the assigned Group, or specify values on the Host to override the Group defaults (`F-01`).
    - Filter saved hosts by name, IP, or tags in the sidebar search box and click **Connect** to open a session immediately.
- **Encrypted Vault, Passwordless Option, Reset & Windows Hello (`S3` — `F-03`)**:
  - DoubleAgent always starts with the **Vault Locked**.
  - On first launch, click **Set Up Vault**:
    - Enter and confirm a **Master Password** and click **Create Vault** to protect `doubleagent.vault` with **Argon2id + XChaCha20-Poly1305**, **OR**
    - Click **Skip Password for Now** to start in passwordless mode and set a Master Password at any time later.
  - Once unlocked, click **Vault Security** in the top bar to:
    - Set or change your **Master Password** (preserving all saved hosts and keys).
    - Click **Enable Windows Hello / Key** to arm native Windows Hello / FIDO2 security-key quick unlock for the current session after an auto-lock.
    - Click **Reset Vault** if you ever forget your Master Password (archives the old vault to `doubleagent.vault.reset.<timestamp>.bak` and starts fresh).
  - Click **Lock Vault** at any time to wipe the encryption key from memory immediately, or let the automatic inactivity timer lock the vault after 15 minutes.
- **Quick Connect & Interactive Terminal (`S1` — `F-01`, `F-06`, `F-07`, `F-11`)**:
  - Enter **Host / IP**, **Port**, **Username**, and **Password** in the top Quick Connect bar and click **Connect SSH**.
  - On first connection to a host, DoubleAgent displays the **Verify Unknown Host Key (`F-06`)** modal with the key algorithm and `SHA256:...` fingerprint.
  - Once connected, an interactive **xterm.js** terminal session opens with 256-color / Truecolor support, automatic window resize (`FitAddon`), and a 10,000-line scrollback buffer.
- **SSH Transport & Host-Key Security (`S2` — `F-01`, `F-04`, `F-06`, `F-07`, `F-20`)**:
  - Supports password authentication, Ed25519 and RSA private keys (with optional passphrase), and keyboard-interactive 2FA prompts.
  - Blocks connections immediately if a previously trusted server changes its host key (`core.ErrHostKeyMismatch`).
  - Strips untrusted `OSC 52` clipboard-write escape sequences from remote terminal output.
