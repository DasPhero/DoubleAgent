# DoubleAgent — User Handbook

Welcome to the DoubleAgent user handbook.

## Overview

DoubleAgent is a cross-platform (Windows and Linux) native SSH client featuring an encrypted local vault, tabbed and split-pane terminals, SFTP file transfers, port forwarding, TOTP generation, per-host notes, and comprehensive penetration testing engagement workflows.

## Understanding the Pentest Workflow Triad: Findings vs. Evidence vs. Notes

DoubleAgent strictly distinguishes between three tiers of operational intelligence:
1. **Notes (Reconnaissance & Scratchpads)**:
   - Unstructured scan logs (nmap, gobuster, linpeas), operator scratchpads, and killchain methodology steps.
   - Associated with a target host or engagement. Notes stay in your documentation vault and are never automatically treated as formal client vulnerabilities.
2. **Evidence Artifacts (Forensic Proof & Artifacts)**:
   - Verified raw proof: terminal dumps, mimikatz outputs, crack results, hash files, or structured tabular data.
   - **Not all evidence needs to be reported:** each evidence artifact has an `inReport` toggle (`📄 In Report` vs `🔒 Internal Vault Only`). Operators can log noisy intermediate proof without polluting the final client deliverables. Multiple evidence artifacts can link to one parent Finding.
3. **Findings (Vulnerabilities & Risk Exposures)**:
   - High-level vulnerabilities, misconfigurations, or weaknesses requiring remediation (e.g. *Privilege Escalation via Sudo NOPASSWD*, *Unquoted Service Path*, *AS-REP Roasting*).
   - Structured with severity rating (`Critical`, `High`, `Medium`, `Low`, `Info`), lifecycle status (`Draft`, `Confirmed`, `Reported`, `Remediated`), description narrative, impact, and remediation guidance.
   - Supported by one or more linked Evidence proof artifacts and killchain Notes.

### Capturing from Terminal Output (Right-Click Context Menu)
Highlighting text in any terminal session displays four quick-save targets:
- `🔑 Save as Credential...`: Heuristically extracts user:pass, API keys, or hashes into the Credential Pool.
- `🛡️ Save as Evidence... [PROOF]`: Preserves output as forensic evidence, with finding attachment and in-report toggle.
- `📝 Save to Notes (Recon)... [RECON]`: Directly logs recon logs and port scan matrices into Host or Engagement Notes.
- `🎯 Create Finding from Selection... [REPORT]`: Generates a structured Finding and attaches the highlighted excerpt as Evidence #1.

## Current Capabilities (`M0`, `M1-1`, `M1-2`, `M1-3`, `F-08`, `F-10`, `F-12`, `F-13`, `F-14`, `F-15`, `F-17`, `F-18`, `F-19`, `F-20`, `F-21`, `F-23`, `F-26`, `F-27`, `F-28`, `F-29`, `F-30`, `F-31`, `F-36`, `F-37`, & `F-40`)

- **Standalone Native App (`M0-0`)**: Launches directly as a single executable on Windows (`DoubleAgent.exe`) and Linux without external runtime dependencies.
- **Terminal Selection Quick Save to Vault (`F-19` / Pentest Module Wave 1)**:
  - **Right-Click Cyberpunk HUD Context Menu**:
    - Highlight any text in an active terminal session and right-click to open the floating HUD Context Menu.
    - Options include: `📋 Copy Selection` (`Ctrl+C`), `🔑 Save as Credential...`, `🛡️ Save as Evidence Finding...`, `⚡ Execute in Terminal`, and `✕ Dismiss` (`Esc`).
    - Smart viewport boundary clamping prevents the context menu from escaping screen borders or overflowing outside the window.
  - **Smart Heuristic Credential Ingestion (`parseCredentialSelection`)**:
    - Automatically analyzes the highlighted selection and infers credential type and structure:
      - **`user:password` & `DOMAIN\user:pass`**: Automatically splits into distinct Username and Secret fields.
      - **Hash Detection**: Recognizes 32-character hexadecimal strings (MD5, NTLM) and 64-character strings (SHA-256) and categorizes them as `hash`.
      - **SSH Private / Public Keys**: Detects `-----BEGIN ...`, `ssh-ed25519`, `ssh-rsa`, and PuTTY keys and categorizes them as `ssh_key`.
      - **API Tokens & JWTs**: Detects `ey...` (JWT), `ghp_` (GitHub), `glpat-` (GitLab), `AKIA` (AWS Access Key), and `Bearer ` authorization tokens.
      - **Plaintext Secret**: Defaults single-line tokens or passwords to `plaintext`.
  - **Automatic Host & Engagement Association**:
    - Resolves the target host directly from the active session ID, tab, or split-pane.
    - If the host belongs to an active Pentest Engagement, the engagement scope is automatically preselected in the save modal.
  - **Save as Evidence Finding**:
    - Instant 1-click conversion of terminal command output, logs, or PoC snippets into an Evidence Finding entry.
    - Pre-populates the excerpt into the finding content field, assigns default category (e.g. `Credentials`, `Privilege Escalation`), and lets operators pick severity rating (`Critical`, `High`, `Medium`, `Low`, `Info`).
  - **Secure Vault Encryption**:
    - Saves directly to the encrypted vault through bound Go methods `SaveCredential` and `SaveEvidence` with HUD confirmation toasts. All secret data remains within the Go process boundary.
- **Evidence Vault & Structured Findings Store (`F-18` / Pentest Module Wave 1)**:
  - **Engagement-Scoped Evidence Vault**:
    - Centralized repository for penetration testing findings, proof-of-concept exploits, discovered vulnerability details, reconnaissance artifacts, and session notes.
    - Open **Tools ▾ &rarr; 🛡️ Evidence Vault (F-18)** or type `evidence` in the Command Palette (`Ctrl+K`).
    - Finding entries are automatically associated with the active engagement and optionally mapped to a specific target host from your inventory.
  - **Pre-filled Default Categories & Custom Categories (Spec Line 56)**:
    - Pre-populated with the 8 standard pentest categories: *Credentials, Open Ports/Services, Vulnerabilities, Privilege Escalation, Lateral Movement, Sensitive Data, Web, and Active Directory*.
    - Operators can create custom categories on-the-fly (`+ Add Category`) to match specific compliance frameworks or custom engagement scopes (e.g. `Cloud Infrastructure`, `Wireless Security`).
  - **Dual-Format Findings: Free Text (Markdown) vs Structured Tables**:
    - **Free Text / Markdown / PoC**: Rich monospace editor with zero-innerHTML Markdown rendering for command outputs, PoC reproduction steps, and remediation guidance.
    - **Structured Table Builder**: Interactive table editor allowing operators to define column headers, add/delete rows, and edit cells directly for structured findings like port scans, discovered services, users/hashes, and endpoint matrices.
  - **Pre-filled Starter Finding Templates**:
    - Instant 1-click loading of common pentest finding templates: *Unquoted Service Path, Sudo NOPASSWD, Discovered Open Ports Matrix, Anonymous SMB Share, AS-REP Roasting, and Exposed .env Secrets*.
  - **Client-Ready Report Export (`.md`)**:
    - 1-click generation and download of formatted Markdown pentest report (`.md`).
    - Includes executive summary severity breakdown (Critical, High, Medium, Low, Info), engagement scope, timeframe, and all findings grouped with structured tables and Markdown PoCs.
- **Engagement Credential Pool, Spray List Generator & Lockout Guard (`F-36`, `F-40` / Pentest Module Wave 1)**:
  - **Engagement-Scoped Credential Pool (`F-36`)**:
    - Manage engagements (assessments, penetration tests, red team operations) with defined scope, timeframes, and active lockout policies.
    - Unified credential store capturing usernames, passwords, hashes (NTLM, SHA-256), Kerberos tickets, API tokens, and SSH keys.
    - Dual-view filtering: browse credentials engagement-wide or filter by specific target host without duplicating records.
    - 1-click clipboard copy, secret reveal toggle (`👁️`), search, category filtering, and direct vault synchronization.
  - **Spray List Generator (`F-36`)**:
    - Export spray-ready files in 5 industry-standard formats:
      - `Usernames Only` (one username per line)
      - `Passwords / Hashes Only` (one secret per line)
      - `Colon Separated (user:password)` (for Hydra, Medusa, crackmapexec)
      - `Cartesian Product (all users x all passwords)`
      - `Spray: Password-First (pass1 for all users, delay, pass2...)` (mitigates lockout risk)
    - Supports combining pool credentials with custom entered user/password lists.
    - Configurable delimiters (`:`, `;`, `|`, tab) and 1-click text file download.
  - **Active Lockout Guard Policy (`F-40`)**:
    - Configurable safety limits per engagement: maximum attempts per account, lockout observation window (e.g., 30 minutes), and mandatory wait delay (e.g., 600s).
    - Real-time pre-flight evaluation before spray generation: alerts if total candidate combinations per user reach or exceed lockout threshold (default 66% warning threshold, 100% hard alert).
    - Displays detailed warning breakdown in the HUD with exact attempt counts, policy limits, and mitigation guidance.
- **Raw TCP Socket Client & Inbound Listener Engine ("Netcat Mode") (`F-31` / Spec Line 64, 140)**:
  - **Direct Raw Socket Terminal (Outgoing Client)**:
    - Dial any TCP host and port with zero SSH handshake overhead directly from DoubleAgent.
    - Open **Tools ▾ &rarr; Raw TCP / Netcat (F-31)**, or type `nc <host> <port>` or `tcp://<host>:<port>` directly in the Command Palette (`Ctrl+K`).
    - **1-Click Presets**: Instant configuration pills for common socket services: `HTTP [80]`, `Redis [6379]`, `SMTP [25]`, and `Shell [4444]`.
    - **Line Buffering & Local Echo Mode**:
      - Solves the typing blindness problem when interacting with raw non-PTY network services (HTTP, Redis, SMTP, Memcached, POP3).
      - DoubleAgent provides interactive local line-editing with backspace and character erasure, transmitting the completed command line upon pressing Enter.
      - 1-click toggle in the terminal toolbar between **Line Mode: ON/OFF** and selectable line endings: **CRLF (`\r\n`)** (default network RFC), **LF (`\n`)**, or **CR (`\r`)**.
  - **Inbound TCP Listener & Reverse Shell Catcher**:
    - Bind a local listening port on `0.0.0.0` or `127.0.0.1` directly from the **Inbound Listener** tab or Command Palette (`listen <port>`).
    - Run multiple concurrent background listeners with real-time status pills (`🟢 ARMED :<port>`), live connection counters (`CATCHES: N`), and start timestamps.
    - **Automatic Terminal Tab Spawning**:
      - When an external target or device connects back (`bash -i >& /dev/tcp/...`, `nc -e /bin/sh`, hardware beacons), DoubleAgent automatically catches the connection and instantly opens an interactive terminal tab (`TCP :4444 ◀ <remoteAddr>`).
      - Sounds a notification chime and displays a status alert banner.
    - **Reverse Shell TTY Upgrade Helpers**:
      - For caught reverse shells that lack a fully interactive PTY, the terminal toolbar features a **`⚡ TTY UPGRADE ▾`** dropdown with 1-click payload injectors:
        - `🐍 Spawn Python3 PTY` (`python3 -c 'import pty; pty.spawn("/bin/bash")'`)
        - `🐍 Spawn Python PTY` (`python -c 'import pty; pty.spawn("/bin/bash")'`)
        - `📟 Export TERM` (`export TERM=xterm-256color`)
        - `⚡ Fix stty raw -echo` (`stty raw -echo; fg`)
        - `🐚 Spawn /bin/sh -i` (`/bin/sh -i`)
- **PuTTY & Termius Session Migration & Import (`F-30` / Spec Line 59, 140)**:
  - **Effortless Migration from Legacy & Cloud Clients**:
    - Migrate all your existing servers, credentials, SSH keys, groups, and port forwardings from PuTTY or Termius directly into DoubleAgent's encrypted vault.
    - Open **Tools ▾ &rarr; Import PuTTY / Termius (F-30)** or via Command Palette (`Ctrl+K` &rarr; "Import PuTTY / Termius").
  - **PuTTY Import (Local Registry & `.reg` Exports)**:
    - **1-Click Local Scan**: On Windows, click **`Scan Local PuTTY Sessions (Registry)`** to automatically read all saved sessions from `HKCU\Software\SimonTatham\PuTTY\Sessions`. On Linux, DoubleAgent scans `~/.putty/sessions/`.
    - **`.reg` File Support**: Upload or paste an exported `.reg` file from another machine.
    - Automatically decodes session names, addresses, ports (including hexadecimal DWORD values), usernames, and parses PuTTY `-L`, `-R`, and `-D` port forwarding strings into active DoubleAgent tunnels.
    - If a session references a local `.ppk` private key file, DoubleAgent automatically imports and encrypts the key inside your vault.
  - **Termius Import (JSON & CSV Exports)**:
    - Drag & drop or upload your `termius.json` or `.csv` export, or paste the content directly.
    - Supports both flat host arrays and nested schema with group hierarchies and tags.
  - **Smart Duplicate Detection & Interactive Preview Table**:
    - Discovered sessions are displayed in a Cyberpunk preview table before anything is saved.
    - Items that already exist in your DoubleAgent vault are flagged with an **`In Vault`** status pill.
    - Easily select or deselect hosts individually or in bulk (`Select All` / `Deselect All`).
    - Choose a destination group (e.g. `Imported from PuTTY` or assign to an existing group).
    - Click **`⚡ Import Selected`** to safely ingest the sessions into your encrypted vault.
- **Encrypted Vault Storage, Cloud Sync (Google Drive / Syncthing) & Conflict Merge (`F-29` / Spec Line 57, 138, 224)**:
  - **Single Encrypted Vault Storage**:
    - All DoubleAgent configurations—saved hosts, groups, credentials, SSH keypairs, port forwarding tunnels, proxy profiles, command snippets, encrypted notes, and TOTP authenticators—are stored inside a single encrypted, tamper-evident envelope file (`doubleagent.vault`).
    - The vault payload is authenticated and encrypted using `Argon2id` + `XChaCha20-Poly1305` with zero unencrypted secrets stored on disk.
  - **Relocate Vault to Cloud Sync Folders**:
    - Want to use DoubleAgent seamlessly across multiple laptops or workstations?
    - Open **Vault ▾ &rarr; Storage &amp; Sync (F-29)** or **Global Settings (`Ctrl+,`) &rarr; ☁️ Storage &amp; Sync**.
    - Under **Relocate Vault Storage Path**, enter the folder path inside your Syncthing, Google Drive, Dropbox, or OneDrive directory (e.g. `D:\Syncthing\DoubleAgent\doubleagent.vault`).
    - Check **"Move current vault file and biometrics to new location"** and click **Relocate Vault**.
    - DoubleAgent automatically updates its persistent location pointer and moves your files.
  - **Automatic External Sync Change Detection**:
    - DoubleAgent tracks file modification timestamps and envelope payload hashes.
    - If another device updates the vault file via Syncthing or cloud drive, DoubleAgent detects it immediately:
      - `🟢 IN SYNC`: Disk copy matches active memory state.
      - `🟡 EXTERNAL CHANGE DETECTED`: Another machine updated the file; click **Scan External Changes** to reload or merge non-conflicting additions.
  - **Cloud Sync Conflict Copy Detection & Smart Merge**:
    - When two machines make changes offline, sync utilities (Syncthing, Google Drive, Dropbox) create conflict duplicate files (e.g. `doubleagent.sync-conflict-*.vault` or `doubleagent (1).vault`).
    - DoubleAgent automatically scans the vault directory for these conflict files and highlights them:
      - A warning pill **`⚠️ SYNC CONFLICT (N)`** appears in the top navigation bar.
      - Each conflict copy is listed under **Cloud Sync Conflict Files** with file size and timestamp.
    - Click **Review &amp; Merge** to launch the Cyberpunk HUD **Vault Merge Conflict Resolver**:
      - **Automatic Merging**: Non-conflicting items added on either machine (new hosts, keys, rules, snippets, notes) are merged automatically without manual intervention.
      - **Side-by-Side Diff Columns**: Any conflicting items (e.g. the same host modified on both machines) are displayed with local vs incoming summaries.
      - **Resolution Options**:
        - **`✓ Keep Local`**: Preserves your local device's version.
        - **`✓ Accept Synced`**: Overwrites local with the incoming synced version.
        - **`⧉ Keep Both (Rename Synced)`**: Preserves both copies, appending `(Synced)` to the incoming item label so no data is ever lost.
      - **Bulk Actions**: `Keep All Local`, `Accept All Synced`, `Keep Both (Rename)`.
      - **Clean Up**: Check **"Delete external conflict copy file after successful merge"** to automatically remove the sync artifact file once merged.
- **Remote File Edit & Auto-Upload with Parallel Conflict Detection (`F-28` / Spec Line 56, 137, 223)**:
  - **In-App Syntax & Line Editor**:
    - Open any text file on the remote server for editing directly from the SFTP File Browser:
      - Select a file and click the **`✏️ Edit`** toolbar button, **OR**
      - Double-click any non-directory file in the remote file tree.
    - Displays line numbers gutter, live character & line counts, and real-time status pills:
      - `✓ Synced` (clean, synchronized with server).
      - `● Unsaved` (amber pill when local buffer contains unsaved changes).
    - Built-in keyboard shortcuts:
      - **`Ctrl+S`**: Save and immediately upload changes to the remote server.
      - **`Tab`**: Indents by 2 spaces instead of losing focus.
  - **Parallel Modification Conflict Detection & HUD Resolution Modal**:
    - When you save, DoubleAgent compares server modification timestamps and content hashes against the snapshot taken when you opened the file.
    - If another user, script, or process modified the remote file on the server in parallel:
      - The normal save is safely blocked to prevent accidental overwrites.
      - An interactive **Parallel Conflict Detected** HUD modal appears with side-by-side metadata:
        - When you opened the file vs. current file state on server (timestamp and size in bytes).
      - **Resolution Controls**:
        - **`Overwrite Remote (Force Upload)`**: Explicitly force-pushes your local version to the server, overriding remote modifications.
        - **`Discard Local & Reload`**: Discards your unsaved local buffer and reloads the fresh server copy.
        - **`Cancel / Keep Local Unsaved`**: Closes the dialog and preserves your local buffer so you can inspect or copy your changes before deciding.
  - **External Editor Auto-Sync**:
    - Click **`Open in Local Editor`** to stage the file and launch it in your system's default text editor (e.g., VS Code, Sublime Text, Notepad++).
    - A background file watcher automatically detects when you press Save in your external editor, verifies timestamps, and auto-syncs the changes to the remote server with real-time HUD status telemetry.
  - **Multi-Window & Workspace Split Integration**:
    - Open as a dedicated full-tab view (`tabType: 'editor'`).
    - Dock into any split workspace pane (`paneType: 'editor'`) side-by-side with live terminals or notes.
    - Undock from split panes back into dedicated standalone tabs with one click.

- **Auto-Reconnect & Workspace Session Restore (`F-27` / Spec Line 136)**:
  - **Automatic Reconnection with Exponential Backoff**:
    - Automatically detects unexpected SSH socket drops (broken pipe, network drops, server timeouts, EOF) and initiates reconnection.
    - Uses an exponential backoff schedule ($2s \to 4s \to 8s \to 16s$, capped at $30s$) to prevent hammering unreachable or restarting servers.
    - **Header Badge & Reconnect HUD Overlay**:
      - Participating pane displays a pulsing amber `⚡ RECONNECTING (Ns)` header badge.
      - Terminal displays a Glassmorphic Reconnect HUD card showing dropped connection reason, live countdown timer, and attempt count ($N/\text{Max}$).
      - Immediate action controls: **`Reconnect Now`** (bypasses countdown to retry immediately), **`Cancel`** (stops the reconnection timer), and **`Close Pane`** (cleans up the pane).
    - If maximum reconnect attempts are exceeded without success, the HUD transitions to **`Connection Terminated`** with a **`Retry Reconnect`** button.
    - Intentional user actions (closing a pane, closing a tab, or clicking Disconnect) are tracked and never trigger auto-reconnect.
  - **Workspace Session & Layout Restore (`workspace.json`)**:
    - Automatically records tab layouts, nested split trees, split ratios, active tabs/panes, dockable notes splits, and launcher panes with debounced writes.
    - Saves layout state to `workspace.json` in user config directory using thread-safe atomic file replacement.
    - **Strict Security Boundary**: The persisted workspace file stores structural layout and host references only—zero plaintext passwords, keys, or credentials are saved.
    - On application startup, the exact tab and split pane geometry is rehydrated. Restored panes display a **`Session Restored`** standby card with a one-click **`Connect Session`** button or seamlessly reconnect once the vault is unlocked.
  - **Connection & Session Settings**:
    - Configurable in **Global Settings (`Ctrl+,`) &rarr; Connection & Session Restore**:
      - **Auto-Reconnect**: Toggle automatic reconnection on unexpected drops.
      - **Max Reconnect Attempts**: Choose between 3, 5, or 10 retry attempts.
      - **Workspace Session Restore**: Toggle saving and rehydrating workspace layout on startup.
- **Broadcast / Multi-Execution Input (`F-26`)**:
  - **Simultaneous Keystroke Dispatch**:
    - Simultaneously sends typed keyboard input, shell commands, and control keys to multiple selected terminal sessions (split panes or tabs).
    - Backed by native Go backend dispatching (`BroadcastInput`) without blocking the system PTY / SSH write loop or freezing the UI renderer.
  - **Prominent Visual Indicators ("Deutliche Markierung")**:
    - **Top Header Status Pill**: Glowing red pill badge (`📡 BROADCAST (N sessions)`) with live pulsing dot and an instant `✕ Disarm` button.
    - **Split Pane Glowing Borders**: All participating terminal panes are highlighted with a glowing red border and inner shadow (`.is-broadcasting`).
    - **Per-Pane Badges & Toggles**: Each participating pane header displays a bright `🔴 BROADCAST` badge and a `📡 ACTIVE` / `📡 Cast` toggle button.
  - **Multiple Broadcast Scopes & Custom Grouping**:
    - **Tab Scope (Default)**: Broadcasts to all split panes within the current active tab (`Alt+B` or toolbar **`📡 Broadcast`**).
    - **All Terminals Scope**: Broadcasts across all open terminal tabs via **Tools ▾ -> Broadcast to All Terminals**.
    - **Custom Selection**: Click **`📡 Cast`** / **`📡 ACTIVE`** on individual pane headers to add or remove specific sessions from the broadcast group on the fly.
  - **Instant Disarm Controls**:
    - Press **`Escape`** or **`Alt+B`**, click **`✕ Disarm`** on the status pill, or click **`Disarm Broadcast Mode`** in the Tools dropdown to instantly disarm broadcast input and return to single-terminal focus.
- **Session Logging & Timestamped Transcripts (`F-21` / Spec Line 131 & 153)**:
  - **Per-Host & Group-Inherited Toggle**:
    - Enable **Session Logging (`F-21`)** when creating or editing a **Host Group** (to automatically record all hosts in that group) or on an individual **SSH Host**.
    - When connecting to a host with Session Logging enabled, DoubleAgent automatically starts recording the session transcript and activates the **`⏺ REC`** badge in the terminal pane header.
  - **Live Per-Session Recording Toggle**:
    - Click **`⚪ Log`** / **`⏺ REC`** in any terminal split-pane header to start or stop timestamped transcript recording on the fly for SSH, local PTY, or serial sessions.
  - **Clean Timestamped Output & ANSI Stripping**:
    - Every recorded line is prefixed with a millisecond-precision timestamp (`[YYYY-MM-DD HH:MM:SS.mmm] `) and stripped of raw ANSI/VT100/OSC control sequences so `.log` files are clean and human-readable.
  - **Password-Echo & Secret Redaction (`Passwort-Echo nie mitschneiden`)**:
    - Automatically detects password, passphrase, PIN, `sudo`, and 2FA/TOTP prompts in terminal streams and suppresses any echoed input characters until newline completion.
    - Passwords and TOTP tokens injected via **Inject Password** or **Inject 2FA Code** are registered with the session logger and scrubbed (`[REDACTED]`) if they ever appear in output.
  - **Session Logs & Recordings Viewer (`Tools ▾ -> Session Logs & Recordings`)**:
    - Browse all active and archived session transcripts, filter by host or date, search lines inside a transcript, copy to clipboard, download `.log` files, export to a custom disk path, stop active recordings, or delete old logs.
    - All transcript lines are rendered via safe React text nodes (never `innerHTML`).

    - Generate new **Ed25519** or **RSA-3072** SSH keypairs directly inside the encrypted Vault (with an optional passphrase).
    - Import existing **OpenSSH PEM** or **PuTTY `.ppk`** (`v2` and `v3`) private keys.
    - Click **Copy Public Key** on any saved key to copy its `authorized_keys` line to the clipboard.
- **SSH Agent & Pageant Integration (`M1-3` — `F-05`)**:
  - When adding a Host, choose **Windows OpenSSH Agent / Pageant (`F-05`)** as the authentication method to authenticate via your OS SSH agent (`\\.\pipe\openssh-ssh-agent`, Pageant shared memory, or Unix `SSH_AUTH_SOCK`) without storing the private key inside the Vault.
- **OpenSSH `ssh_config` Import (`M1-3` — `F-22`)**:
  - Click **Import `ssh_config`** in the top bar and paste your `~/.ssh/config`.
  - Automatically imports `Host`, `HostName`, `User`, `Port`, `IdentityFile`, and `ProxyJump`, and displays clear warnings for any unsupported directives.
- **One-Click Password Injection into Active Terminal Sessions**:
  - While connected to an SSH terminal session, click **Inject Password** in the terminal toolbar to have the Go backend write the stored password directly into the remote PTY (`stdin`) for `sudo` / `su` prompts without ever exposing the password to the frontend.
- **Command Palette & Quick Connect (`M1-2` — `F-02`)**:
  - Press **`Ctrl+K`** (or click **Command Palette (`Ctrl+K`)** in the top bar) from anywhere in the workspace.
  - **Fuzzy Search**: Type fragments or subsequences of a host's **Name** (e.g. `pw01` for `prod-web-01`), **IP/Hostname**, or **Tags** (e.g. `nginx`) and press `Enter` (or click the result) to connect immediately.
  - **Direct `user@host:port` Quick Connect**: Type `user@host:port`, `user@host`, `host:port`, or `ssh -p 2222 user@host` into the Command Palette to connect to an ad-hoc SSH target directly.
- **Hosts & Groups Management with Inheritance (`M1-1` — `F-01`)**:
  - Once unlocked, use the left **Hosts & Groups** sidebar:
    - Click **+ Group** to create hierarchical folders with default **Port**, **Username**, and **Keepalive** settings.
    - Click **+ Host** to save an SSH host inside the encrypted Vault. Leave Port (`0`) or Username empty to inherit them automatically from the assigned Group, or specify values on the Host to override the Group defaults (`F-01`).
    - Filter saved hosts by name, IP, or tags in the sidebar search box and click **Connect** to open a session immediately.
- **Encrypted Vault, Passwordless Option, Reset & Windows Hello (`S3` — `F-03`)**:
  - DoubleAgent always starts with the **Vault Locked**.
  - On first launch, click **Set Up Vault**:
    - Enter and confirm a **Master Password** and click **Create Vault** to protect `doubleagent.vault` with **Argon2id + XChaCha20-Poly1305**, **OR**
    - Click **Skip Password for Now** to start in passwordless mode and set a Master Password at any time later.
  - Once unlocked, click **Vault Security** in the top bar to:
    - Set or change your **Master Password** (preserving all saved hosts and keys).
    - Click **Enable Windows Hello / Key** to arm native Windows Hello / FIDO2 security-key quick unlock for the current session after an auto-lock.
    - Click **Reset Vault** if you ever forget your Master Password (archives the old vault to `doubleagent.vault.reset.<timestamp>.bak` and starts fresh).
  - Click **Lock Vault** at any time to wipe the encryption key from memory immediately, or let the automatic inactivity timer lock the vault after 15 minutes.
- **Quick Connect & Interactive Terminal (`S1` — `F-01`, `F-06`, `F-07`, `F-11`)**:
  - **New Connection Workspace & Split Launcher ("Out of Thin Air")**:
    - Open new connection splits or tabs at any time by clicking the **`+`** tab button, **`+ View ▾ -> New Connection View`**, or **`View ▾ -> New Connection Split`**.
    - Displays a wide, responsive glassmorphic card with the DoubleAgent emblem and horizontal header text.
    - **Adaptive Layout**: Automatically organizes into 3 equal columns (`Local Shells`, `Terminal Directory Spawning`, `Remote & Serial`) when wide, and cleanly collapses into 1 vertical column when the window or split pane is narrow (preventing awkward 2-column wrapping).
    - **Direct SSH Connection with Multiple Authentication Modes**:
      - Connect directly to ad-hoc servers by entering `[User] @ [Host / IP] : [Port]`.
      - Supports switching authentication methods:
        - **Password**: Enter password (optional) for standard password/keyboard-interactive login.
        - **SSH Key**: Select any private key stored in the Keychain (`vaultSummary.keys`) with an optional key passphrase. Private keys are securely resolved inside the Go backend by `KeyID` and never exposed to the frontend WebView.
        - **SSH Agent**: Authenticate via Windows OpenSSH Agent or Pageant.
      - On narrow panes or windows, input fields and authentication options stack into a clean vertical column with a full-width **Connect SSH** action button.
    - Connecting to a host or spawning a local shell inside a New Connection split replaces that launcher pane in-place with the active terminal session.
  - On first connection to a host, DoubleAgent displays the **Verify Unknown Host Key (`F-06`)** modal with the key algorithm and `SHA256:...` fingerprint.
  - Once connected, an interactive **xterm.js** terminal session opens with 256-color / Truecolor support, automatic window resize (`FitAddon`), and a 10,000-line scrollback buffer.
- **SSH Transport & Host-Key Security (`S2` — `F-01`, `F-04`, `F-06`, `F-07`, `F-20`)**:
  - Supports password authentication, Ed25519 and RSA private keys (with optional passphrase), and keyboard-interactive 2FA prompts.
  - Blocks connections immediately if a previously trusted server changes its host key (`core.ErrHostKeyMismatch`).
  - Strips untrusted `OSC 52` clipboard-write escape sequences from remote terminal output.
